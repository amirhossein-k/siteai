# بهینه‌سازی صفحه اول برای هدیه و تبدیل

## تغییرات

- «پیشنهادهای ویژه امروز» و «پرفروش‌ترین محصولات» قبل از دسته‌بندی‌ها قرار گرفتند.
- بخش هدیه بلافاصله بعد از دسته‌بندی‌ها قرار گرفت.
- بخش هدیه با پیام راهنما، CTA جست‌وجوی هوشمند، عنوان مناسبتی و کارت‌های تصویری/کمپینی تقویت شد.
- برای دیتابیس‌هایی که هنوز دقیقاً ترتیب پیش‌فرض قدیمی را دارند، migration امن ترتیب جدید را اعمال می‌کند؛ اگر ادمین قبلاً ترتیب را تغییر داده باشد، آن ترتیب دست‌نخورده می‌ماند.
