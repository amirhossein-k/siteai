# معرفی دستیار هوشمند برای بازدید اول

در اولین بازدید هر مرورگر، بعد از ۹۰۰ میلی‌ثانیه یک پیام کوچک کنار دکمه دستیار نمایش داده می‌شود. پیام توضیح می‌دهد که دستیار می‌تواند بر اساس نیاز و بودجه برای انتخاب محصول کمک کند و دکمه «شروع گفتگو» دارد.

با بستن پیام، شروع گفتگو، یا کلیک روی دکمه شناور دستیار، پیام با کلید `localStorage` ذخیره و در بازدیدهای بعدی نمایش داده نمی‌شود. اگر `localStorage` در مرورگر در دسترس نباشد، پیام برای جلوگیری از مزاحمت نمایش داده نمی‌شود.

فایل تغییرکرده:
- `src/components/storefront/ai/ai-shopping-assistant.tsx`

بررسی static انجام شد. تست runtime در محیط تحویل به‌دلیل نبود npm اجرا نشد.
