# بسته ارتقای سئو، UI/UX و دستیار هوشمند مارلو شاپ (`siteai`)

این پکیج شامل تمام فایل‌های ارتقا یافته و جدید برای پروژه `amirhossein-k/siteai` است.

## فایل‌های موجود در این بسته
1. `PROMPT.md`: پرامپت مهندسی‌شده و جامع برای اجرای گام‌به‌گام تغییرات.
2. `src/lib/constants.ts`: اصلاح نام برند به **«مارلو شاپ»**، توضیحات متای غنی و کلمات کلیدی سئو.
3. `src/app/layout.tsx`: افزودن `keywords`، `canonical` و بهینه‌سازی تایتل و OpenGraph برای گوگل.
4. `src/components/storefront/home/lazy-section.tsx`: رفع باگ بزرگ عدم ایندکس شدن سکشن‌های صفحه اصلی در گوگل با فعال‌سازی `seoPreRender` و `content-visibility: auto`.
5. `src/lib/homepage-config.ts`: جایگزینی متن‌های تستی با کپی‌رایتینگ حرفه‌ای فروشگاهی.
6. `src/app/api/ai-assistant/route.ts`: اندپوینت دستیار هوشمند خرید و پیشنهاددهنده محصول (با Rate-Limit و امتیازدهی هوشمند بر اساس تخفیف، فروش و ارتباط).
7. `src/components/storefront/ai/ai-shopping-assistant.tsx`: ویجت شناور مشاور هوشمند خرید با چیپ‌های آماده و کارت‌های محصول.
8. `src/components/storefront/sticky-mobile-buy-bar.tsx`: نوار چسبان خرید سریع در موبایل برای افزایش نرخ تبدیل.
9. `src/app/page.tsx` و `src/app/(storefront)/layout.tsx`: اتصال دستیار هوشمند و رندر سئو محور در صفحه اصلی و صفحات فروشگاه.

## نحوه اعمال روی پروژه
کافیست محتویات پوشه `src` داخل این فایل زیپ را در روت پروژه خود کپی و جایگزین (Overwrite) کنید و سپس دستور زیر را اجرا کنید:
```bash
npm run check && npm run build
```

## اتصال به مدل زبانی واقعی

مسیر `/api/ai-assistant` اکنون با API سازگار با Anthropic متصل می‌شود. کلید را هرگز داخل کد، ZIP یا فرانت‌اند قرار نده؛ فقط در Environment Variables سرویس Chabokan/سرور تنظیم کن:

```env
ANTHROPIC_BASE_URL=https://ai.chabokan.net
ANTHROPIC_AUTH_TOKEN=کلید-واقعی-خودت
ANTHROPIC_MODEL=nvidia/nemotron-3-ultra-550b-a55b:free
```

اگر متغیرها تنظیم نباشند یا سرویس مدل در دسترس نباشد، دستیار به‌صورت امن روی موتور رتبه‌بندی داخلی فروشگاه fallback می‌کند. کلید نمونه‌ای که در چت فرستادی در فایل‌ها ذخیره نشده است.

## ارتقای تخصص حوزه مارلو شاپ

دستیار حالا قبل از فراخوانی مدل، سلام و سؤال‌های خارج از حوزه را تشخیص می‌دهد و از مصرف بی‌دلیل مدل جلوگیری می‌کند. برای سؤال‌های مرتبط، دانش ثابت فروشگاه به prompt اضافه می‌شود و مدل موظف است درباره قیمت، موجودی، تخفیف و مشخصات فقط به کاتالوگ واقعی محصول تکیه کند؛ پاسخ‌های خارج از داده را حدس نمی‌زند.

## تغذیه دانش فروشگاه از دیتابیس

route دستیار بعد از اتصال به MongoDB یک snapshot زنده از تعداد محصولات فعال و موجود، محصولات تخفیف‌دار، دسته‌بندی‌های فعال و برندهای فعال می‌گیرد و آن را به مدل می‌دهد. پاسخ API اکنون `meta.knowledgeSource` دارد: مقدار `mongodb` یعنی snapshot زنده موفق بوده و `static-fallback` یعنی فقط دانش ثابت استفاده شده است.

## کاهش هزینه و زمان پاسخ دستیار

- snapshot دانش فروشگاه ۳۰ ثانیه cache می‌شود تا هر پیام چهار query تکراری به MongoDB نزند.
- لیست دسته‌ها و برندهای داخل prompt از ۶۰ به ۲۰ مورد محدود شده است.
- سقف خروجی مدل پیش‌فرض از ۴۵۰ به ۳۲۰ توکن کاهش یافته و با `ANTHROPIC_MAX_TOKENS` قابل تنظیم است.
- timeout پیش‌فرض مدل ۱۴ ثانیه است و با `ANTHROPIC_TIMEOUT_MS` قابل تنظیم است؛ در خطا پاسخ داخلی سریع‌تر برمی‌گردد.

```env
ANTHROPIC_MAX_TOKENS=320
ANTHROPIC_TIMEOUT_MS=14000
```
