# محصولات مرتبط در صفحه محصول

در انتهای صفحه هر محصول، یک rail با عنوان «پیشنهادهای مرتبط برای شما» اضافه شد. API محصولات فعال و موجودی‌دار را با توجه به دسته، برند و tagهای محصول فعلی پیدا می‌کند؛ محصولات بازدیدشده اخیر امتیاز بیشتری می‌گیرند و حداکثر ۸ پیشنهاد نمایش داده می‌شود. بازدیدهای اخیر فقط با شناسه محصول در localStorage ذخیره می‌شود و اطلاعات حساس یا حساب کاربر ذخیره نمی‌شود.

فایل‌ها:
- `src/app/api/products/[id]/related/route.ts`
- `src/components/storefront/related-products.tsx`
- `src/app/(storefront)/products/[slug]/page.tsx`

بررسی static و سلامت ZIP انجام شد. تست runtime در محیط تحویل به‌دلیل نبود npm اجرا نشد.
